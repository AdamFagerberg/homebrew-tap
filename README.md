# AdamFagerberg Tap

## How do I install these formulae?

`brew install adamfagerberg/tap/<formula>`

Or `brew tap adamfagerberg/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "adamfagerberg/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
